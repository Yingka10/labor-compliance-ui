# 小勞鼠 — 決賽簡報亮點整理

> 本檔彙整本輪迭代為系統做的「有價值的改變」與背後原因,供決賽簡報取材。
> 核心定位:**不只給答案,而是給「可當場驗證、可留存、可行動」的勞動合規研判。**

---

## 一句話差異化(簡報開場可用)

市面上的法遵問答多半「給一段看起來合理的文字」。小勞鼠的每一條法規都**點得開官方原文**、每一個風險數字都**來自真實裁罰資料**、每一次諮詢都能**一鍵生成案件報告或諮詢摘要**——把「問完就忘」的對話,變成「可驗證、可留存、可行動」的合規成果。

評審現場可做的事:點任一法條 → 跳全國法規資料庫官方條文;看任一風險數字 → 對照知識圖譜裁罰案例;問完一題 → 立案生成報告或匯出摘要 PDF。

---

## 主軸一:真實性與可驗證(防幻覺,評審可當場核對)

### 1. 法規引用全面連到官方原文,涵蓋 26 部勞動法規
- **做了什麼**:建立一張對「全國法規資料庫」逐一查證的 pcode 對照表(26 部:勞基法及施行細則、勞退條例、職安法、性平法、就服法、就保法、勞工保險條例、勞工職業災害保險及保護法、勞資爭議處理法、大量解僱勞工保護法、勞動事件法、最低工資法、民法、刑法…),並支援簡稱與舊名(勞基法、職安法、災保法、性別工作平等法等)自動對應。每條引用產生 `LawSingle?pcode=&flno=` 的**單條深連結**(直接跳到第 N 條,而非整部法規)。
- **為什麼有價值**:法遵產品最怕「條號講錯、內容唬人」。能一鍵點到官方原文,等於把每個論述都附上**可即時驗證的出處**,直接回應評審對 AI 幻覺的疑慮。

### 2. 法條卡片從「手寫摘要」升級為「即時 API + 官方連結」
- **做了什麼**:法條卡片的條號來自即時 API(知識圖譜 cyphers + 回答本文比對 + 標註段三層合併),條文全文改連官方原文,移除過去人工撰寫的法條摘要。
- **為什麼有價值**:人工摘要會過時、可能與現行條文不符;改連官方原文後,內容**永遠是現行有效版本**,且來源權威。

### 3. 一套 `linkifyLawText` 讓全站法規都可點
- **做了什麼**:寫一個掃描器,凡文字裡出現「職安法 §37」「勞退條例 §12」這類引用就轉成官方連結(有條號連單條、僅法名連整部法)。套用到**法定義務時間軸、權益主張時效、應備文件清單、聊天法條卡片**四處。
- **為什麼有價值**:可驗證性不是只有聊天有,而是**貫穿整個產品**;使用者在任何地方看到法條都能立刻查證。

## 主軸二:專業誠實——法律內容分級與校正

### 4. 「法定 vs 建議」分級,不把建議事項冒充法律義務
- **做了什麼**:法定義務時間軸與應備文件清單,逐項標示「**法定期限 / 建議時程**」「**法定 / 建議文件**」。法定者附查證過的法條(如出勤紀錄勞基法 §30、工資清冊 §23、資遣通報就服法 §33、資遣費勞退條例 §12、職災通報職安法 §37),建議者明確標為「非每案必備的佐證」。
- **為什麼有價值**:真正的法務專業在於**分得清什麼是法律強制、什麼是實務建議**。這個分級讓系統不會誤導使用者「以為全部都是義務」,展現產品的專業可信度。

### 5. 時效與義務天數對條文校正,爭議如實標示
- **做了什麼**:請求權時效逐項對法條校正(職災補償 2 年/勞基法 §61、工資 5 年/民法 §126…);**修正一個真實錯誤**——原本把資遣費時效寫成 5 年(誤用退休金的 §58),改為如實呈現「實務見解分歧:勞動部採 15 年、部分法院採 5 年」。義務時間軸的天數也對齊條文(工資即結清/施行細則 §9 vs 資遣費 30 日內/勞退條例 §12 拆開)。
- **為什麼有價值**:對「法律見解分歧」的議題不假裝有標準答案,而是誠實呈現各方見解——這正是法務人員信任一個工具的前提。

### 6. 風險定價只用真資料,聚合範圍誠實標示
- **做了什麼**:同類裁罰案例的「件數 / 罰鍰中位數 / 最高額 / 代表案例」**只聚合 API 回傳的真實裁罰資料**;查無資料時誠實顯示「本次未取得相似裁罰案例」而非編造數字。並標明統計範圍(取自本次查詢結果、非全量圖譜;涵蓋哪些事故類型;未依產業精準篩選)。
- **為什麼有價值**:風險定價是這套系統最有說服力的「量化」賣點,正因如此**數字必須可信**;寧可標示資料不足,也不用假數據撐場面,反而更顯可靠。

## 主軸三:完整諮詢閉環(諮詢 → 立案 → 報告 → 續問)

### 7. 案件調查四區塊報告 + 身分分流
- **做了什麼**:案件調查輸出結構化四區塊報告:**案件摘要(AI 研判,逐字串流)/ 法定義務時間軸 or 權益主張清單 / 風險定價 / 應備文件清單**。依身分分流——資方走「義務與風險」、勞工走「權益主張」模板。
- **為什麼有價值**:把一段問答升級為**可交付的決策文件**;同一案件,雇主看到的是合規義務與罰則風險,勞工看到的是可主張的權益與救濟管道,一套系統服務勞資雙方。

### 8. 規則引擎:法定義務時間軸 + 資遣費/預告期試算
- **做了什麼**:由表單錨點日期推算各項法定義務的具體到期日(逾期紅色、緊急倒數、可勾選);資遣情境內嵌資遣費與預告期試算,支援**勞退新制(0.5 月/年、上限 6 月)與舊制(1 月/年、無上限)**、預告期 10/20/30 日、謀職假。行動清單完成度連動風險燈號。
- **為什麼有價值**:從「告訴你有哪些義務」進化到「**算給你看期限與金額**」,提供 AI 文字之外的確定性計算,直接可用於實務作業。

### 9. 諮詢摘要 ── 依身分分流的「可帶著走」行動文件(獨立第三頁)★ 重點特色
- **做了什麼**:問答回答下方可「匯出為諮詢摘要」,存入獨立的「諮詢摘要」頁(版面比照案件調查:左列表、右內容),可**下載 Word(可編輯/簽核)或 PDF(列印)**、繼續諮詢(刻意不給開發者格式 Markdown,因為使用者是 HR / 勞工)。關鍵是**同一段問答,兩種身分匯出用途完全不同的文件**:
  - **資方 / HR →「合規處理摘要」**:應辦事項(附法條與法定/建議)+ 裁罰風險 + 應留存文件,有摘要編號/日期,讀起來像一份可歸檔、可簽核的合規研判紀錄。
  - **勞工 →「權益主張摘要」**:可主張權益 + 救濟管道(攤開「找哪個窗口」:1955 專線、地方勞工局、勞保局…)+ 請求權時效 + 需備證據,像一份帶去勞工局可照著走的行動指南。
  - 「下一步」一律做成**可勾選清單**,匯出 Word / PDF 後仍是可打勾的檢查表 —— 把「資訊」變成「行動」。
- **為什麼有價值**:摘要的價值不在「換個格式變漂亮」,而在**離開系統後還能用**。使用者問完不會留在小勞鼠裡,他要拿這份東西去做下一件事 —— HR 拿去歸檔/報告主管(出事時是「我有盡職調查」的證明)、勞工拿去申訴/申請給付。這正是「**同一個法規大腦,資方看怎麼合規、勞工看怎麼維權**」最具體的展現,也是把既有的身分切換推到極致的特色武器(複用 obligations / claims / documents 等既有資產,不是另造功能)。

### 10. 固定雙出口按鈕 + 三頁串接,意圖由使用者決定
- **做了什麼**:每則回答下方固定提供兩顆按鈕——「立案調查並生成報告」「匯出為諮詢摘要」(所有情境、所有問題都顯示,系統不猜使用者要哪個)。報告與摘要都可「繼續諮詢」帶上下文回到對話續問,形成 **諮詢 → 立案/摘要 → 報告 → 續問** 的閉環。
- **為什麼有價值**:不替使用者預設意圖,而是把選擇權交給人——這是 to-B 專業工具該有的設計;三頁之間順暢串接,展現的是**完整工作流**而非零散功能。

## 主軸四:情境適配與適用廣度

### 11. 法規雷達情境改以「風險盤點」呈現
- **做了什麼**:法規雷達沒有具體事故日,不套用職災的時間軸模板;改以「**風險盤點 · 高風險法條 Top N**」呈現——依裁罰案例數聚合最常被罰的法條(連官方原文),搭配裁罰趨勢與建議內控文件。
- **為什麼有價值**:同一套系統能依情境**自動切換最合適的呈現方式**(個案走時間軸、總體走風險盤點),而不是硬塞同一個模板,展現產品設計的成熟度。

### 12. 聚焦資訊服務業,底層架構仍可擴充
- **做了什麼**:demo 以資訊服務業(IT)為主軸——資料、情境與裁罰統計都鎖定 IT 行業,讓回答更精準、貼近評審熟悉的痛點。
- **為什麼有價值**:先把單一產業做深做準(可信度),底層圖譜與規則引擎並未綁死產業、可複製到其他行業(可規模化);demo 聚焦、敘事不發散。

## 主軸五:技術紮實度(被問到時的底氣)

- **真實串接 Hybrid RAG 後端**:智能問答與案件調查報告都接真實 EAP API(VectorRAG + GraphRAG + 統合 Agent),經自建 Express proxy 處理 CORS、隱藏 token、注入身分前綴,並原樣透傳 SSE、前端逐字串流渲染。
- **知識圖譜直接驅動產品**:API 回傳的 cyphers(實際執行的 Cypher 查詢 + 結果)同時驅動**風險定價、推理路徑視覺化、法條卡片**——可在 demo 直接展開「查看 Cypher」證明圖譜真的被查詢,而非裝飾。
- **企業級前端規範**:淺色底 + 深藍主色、繁體中文、無 emoji 的正式 to-B 介面;跨頁狀態以 session 共享(不依賴 localStorage)。

## 簡報敘事建議(把上面收斂成三句)

1. **可驗證**:每條法規連官方原文(26 部查證)、每個數字來自真實裁罰圖譜——直球對決 AI 幻覺疑慮。
2. **夠專業**:法定/建議分級、時效爭議如實標示、資料不足就誠實說——法務敢用的誠實工具。
3. **能行動**:諮詢 → 立案報告(含期限與資遣費試算)→ 諮詢摘要(可下載/PDF)→ 續問,一條龍閉環。
