# 三大情境規格

> 狀態(2026-06):三情境的問答與案件調查報告皆已實作並串接真實 API。
> 範例問題、表單欄位、報告四區塊均已落地;報告輸出見各情境「報告區塊」。
> 法律內容(義務天數、時效、文件清單)已對照法條校正並區分「法定 / 建議」,仍建議正式上線前經法務複核。

## 情境一:應急導航 — 職災處置
- 使用者:HR / PM / EHS
- 核心用途:判斷職災類型、責任邊界、法定義務、應備文件、罰則與刑事/民事風險

### 範例問題 chips(智能問答頁)
- 「工程師在客戶機房駐點時受傷,算職業災害嗎?雇主責任怎麼認定?」
- 「發生職災後 8 小時內要通報嗎?哪些情況必須通報勞檢機構?」
- 「過往有無類似的駐點工程師職災裁罰案例?」 ← graph 類問題
- 勞工視角另有對應版本(身分切換)。

### 案件調查表單欄位
- 事故日期(date,時間軸錨點)
- 事故地點類型(select:公司內 / 客戶端駐點 / 居家辦公 / 通勤途中)
- 傷害程度(select:輕傷 / 需住院 / 失能 / 死亡)
- 受僱型態(select:正職 / 派遣 / 承攬外包)
- 是否已通報勞檢機構(radio:是 / 否)
- 事故經過簡述(textarea,可由問答帶入)

### 報告輸出(四區塊,已實作)
- 案件摘要(AI 研判,串流)
- 法定義務時間軸:8 小時通報(職安法 §37)等,逾期紅色、緊急倒數、可勾選;區分法定/建議
- 風險定價:同類裁罰案例件數 / 罰鍰中位數 / 最高額(取自 API cyphers)
- 應備文件清單(可勾選)

## 情境二:精準止損 — 資遣爭議
- 使用者:HR / 法務
- 核心用途:檢查資遣程序、通知期限、舉證資料、調解與工資爭議風險

### 範例問題 chips
- 「想用勞基法 11 條第 5 款資遣績效不佳的工程師,程序上要注意什麼?」
- 「資遣通知期與謀職假怎麼計算?年資 3 年 2 個月的員工要給幾天?」
- 「同業有沒有因資遣程序瑕疵被裁罰或敗訴的案例?」 ← graph 類問題

### 案件調查表單欄位
- 資遣事由(select:勞基法 11 條各款)
- 員工年資(number:年 / 月,兩個獨立欄位)
- 適用退休金制度(radio:勞退新制 / 舊制,影響資遣費計算)
- 是否有績效改善紀錄 PIP(radio)
- 是否已預告(radio)
- 預定資遣生效日(date,時間軸錨點)
- 月平均工資(number,計算資遣費)
- 爭議說明(textarea,可由問答帶入)

### 報告輸出(四區塊,已實作)
- 案件摘要(AI 研判,串流)
- 法定義務時間軸:資遣 10 日前通報(就服法 §33)、工資即結清(施行細則 §9)、資遣費 30 日內(勞退條例 §12)等
- 內嵌資遣費 / 預告期試算(新制 0.5 月/年上限 6 月、舊制 1 月/年無上限;預告 10/20/30 日;謀職假)
- 風險定價 + 應備文件清單
- 勞工身分則改顯示「權益主張清單」(給付項目 / 救濟管道 / 請求權時效)

## 情境三:法規風險雷達
- 使用者:管理層 / HR
- 核心用途:依公司情境查詢同業(資訊服務業)裁罰趨勢,找出最容易違規的法條與內控缺口

### 範例問題 chips
- 「我們這行近年最常被裁罰的勞基法條文是哪些?」 ← graph 統計類問題
- 「同業因加班費計算錯誤被裁罰的金額分布?」 ← graph 統計類問題
- 「以 50 人規模的公司,勞檢最常查的項目與該準備的內控文件?」

### 案件調查表單欄位
- 公司規模(select:30 人以下 / 30-99 / 100-499 / 500+)
- 工時制度(select:標準工時 / 變形工時 / 責任制核備)
- 關注面向(multi-select:工時 / 加班費 / 職災 / 資遣 / 性平)
- 補充說明(textarea)

### 報告輸出(風險盤點版,已實作)
- 案件摘要(AI 研判) + **風險盤點 · 高風險法條(依 cyphers 聚合各法條裁罰案例數 Top N,連官方原文)** + 風險定價(裁罰趨勢) + 應備內控文件清單。
- 無具體事故日,不套用法定義務時間軸(以風險盤點取代)。

## 身分切換
- 預設身分:資方 / HR;可切換勞工。
- 問答:換 chips 與 role 前綴(proxy 注入);報告:資方走「義務與風險」模板、勞工走「權益主張」模板。
