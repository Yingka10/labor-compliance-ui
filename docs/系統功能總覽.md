# 小勞鼠 · 勞動合規風險助手 — 系統功能總覽

> 這份文件介紹「整個系統現在能做什麼」，供 demo、報告、新成員上手用。
> 一句話：**一個結合 Hybrid RAG（VectorRAG 法條原文 + GraphRAG 推理鏈）的勞動合規風險助手，企業 HR / 管理層查「怎麼合規」，勞工查「怎麼維權」——同一個知識大腦、兩種視角。**

---

## 一、整體架構

```
使用者(瀏覽器)
   │
   ▼
前端 React + Vite + Tailwind  ── 三大頁面 + 證據區 + 規則引擎
   │  POST /api/ask (SSE)
   ▼
Express Proxy(server/index.js) ── 藏金鑰 / 解 CORS / 注入圖譜路由指令 + 身分 / 並行搶答
   │
   ▼
EAP(Gemini Data)Hybrid RAG ── VectorRAG(32 份 PDF 原文) + GraphRAG(3,868 節點/2,410 邊) + 統合 Agent
```

- 後端是組員維護的 EAP v6「咕咕嘎嘎」專案（50 條 Data Flow）。
- 前端只負責介面 + 規則引擎；proxy 負責安全與穩定性（詳見 `系統端調整總結_2026-06.md`）。

## 二、三大功能頁

### 1. 智能問答（/chat）— 自然語言問答 + 證據攤開

使用者用白話問勞動法規問題，系統即時串流回答，並把「依據」攤在答案下方。

能做什麼：
- **自然語言提問**：打字或點**範例問題 chips**（已挑選會打中 graph 的問句）。
- **身分切換**：資方 / 勞工，同一題不同立場（身分前綴在 proxy 注入）。
- **逐字串流回答**：含表格、清單、Mermaid 圖。
- **證據區三 tab**（只有有資料才出現）：
  - **相關法條**：條號來自即時查詢 + 本文比對 + 標註段，每條**連全國法規資料庫官方原文**。
  - **參考來源**：引用文件清單（節點編號已還原成「診斷證明書、出勤紀錄…」中文名）。
  - **推理路徑**：右側抽屜，顯示本次查詢**實際命中的圖譜節點類型與數量**（路徑視角）＋**真實 Cypher 全文**（技術視角）——證明真的走了 GraphRAG。
- **延伸問題 chips**：依本次回答**動態產生**的追問，一點直接續問。
- **固定出口按鈕**：「立案調查並生成報告」（帶問題去填表）、「匯出為諮詢摘要」。
- **對話紀錄**：左欄多對話切換（session 內）。

### 2. 案件調查（/investigate）— 結構化風險報告

三步引導：**選情境 → 填參數 → 生成報告**，輸出依「情境 × 身分」分流的四區塊報告。

四區塊：
- **案件摘要**：AI 研判段落（串流；失敗退回本地規則摘要並可重試）。
- **區塊二（依情境 × 身分）**：
  - 資方 · 職災 / 資遣：**法定義務時間軸** —— 規則引擎依錨點日期推算各義務到期日，逾期紅標、緊急倒數、**可勾選**，並區分「法定期限 vs 建議時程」。
  - 資方 · 法規雷達：**同業高風險項目** —— 依裁罰統計聚合（資訊服務業可回工時/加班類 vs 投保類件數對比）。
  - 勞工：**權益主張清單** —— 可主張給付 / 救濟管道 / 請求權時效。
- **風險定價**：聚合裁罰案例（件數 / 罰鍰中位數 / 最高額 / 代表案例）；**無真實資料時誠實標示、不造數字**。
- **應備文件清單**：依情境 × 身分，**可勾選**，每項標「法定 / 建議」、法定者連官方原文。
- **資遣情境**：內嵌**資遣費 / 預告期試算**（勞退新制 0.5 月、舊制 1 月；預告期 10/20/30 日；謀職假）。
- **風險燈號連動**：行動清單（時間軸 + 文件）完成度會即時調整高/中/低燈號。

### 3. 諮詢摘要（/summary）— 可攜出的決策文件

把一段問答整理成可歸檔 / 帶走的文件，**依身分分流**：
- 資方 →「**合規處理摘要**」：應辦事項 + 依據法條 + 裁罰風險 + 應留存文件（像盡職調查紀錄）。
- 勞工 →「**權益主張摘要**」：可主張權益 + 找哪個窗口 + 請求權時效 + 需備證據（像帶去勞工局的行動指南）。

能做什麼：
- 「下一步」是**可勾選清單**（匯出後仍可打勾）。
- **下載 Word / 下載 PDF**（含官方法條超連結，無第三方套件）；面向 HR/勞工，不提供開發者格式。
- 「繼續諮詢」帶上下文回到問答。

## 三、三頁怎麼串起來

```
智能問答 ──「立案調查並生成報告」──▶ 案件調查(預填表單)
        └─「匯出為諮詢摘要」──────▶ 諮詢摘要
案件調查 ──「就此案件繼續諮詢」────▶ 智能問答(帶案件上下文)
諮詢摘要 ──「繼續諮詢」───────────▶ 智能問答(帶摘要上下文)
```

一條龍：問 → 立案出報告 → 匯出可攜文件 → 隨時帶上下文回去再問。

## 四、三大情境 × 雙身分（系統能回答的範圍）

| 情境 | 資方 / HR 視角 | 勞工視角 |
|---|---|---|
| **職災處置（應急導航）** | 事故類型判定、法定通報義務與期限/單位、應備文件、刑責與民事賠償風險 | 可請領的職災給付、申請文件、受理單位、舉證 |
| **資遣爭議（精準止損）** | 合法資遣程序與預告期、資遣費試算、舉證責任與工資推定風險、調解前置 | 被資遣可主張的權益、申訴管道、需備證據 |
| **法規風險雷達（同業合規）** | 同業最常被裁罰的違規類型/法條與件數金額、內控缺口與改善建議 | 該產業常見違規地雷、自保與檢舉管道 |

## 五、貫穿全系統的能力

- **Hybrid RAG 證據可攤開**：法條原文（Vector）+ 推理鏈與同業裁罰（Graph），且推理路徑/ Cypher 可檢視。
- **同一知識庫雙視角**：資方看合規、勞工看維權，一鍵切換。
- **法律內容可信度**：法條一律連官方原文（涵蓋 26 部勞動法規 + 簡稱對照）；天數/時效對照條文校正並標「法定 vs 建議」；無真實裁罰數據時誠實標示、不造數字。
- **demo 穩定性**：proxy 注入圖譜路由指令 + 並行搶答，把機率性的後端拉到實測高命中（單次 ~25% → 3/3）。
- **企業感 UI**：淺色底、深藍主色、繁體中文、無 emoji 雜訊（投影清晰）。

## 六、技術與資料

- **前端**：React + Vite + Tailwind；react-router；react-markdown + remark-gfm；mermaid；跨頁狀態 React Context（session、不用 localStorage）。
- **Proxy**：Node.js Express（`server/index.js`）。
- **規則引擎（前端）**：`deadlines.js`（時間軸）、`severance.js`（資遣試算）、`riskPricing.js`（裁罰聚合）、`claims.js`/`documents.js`/`obligations.js`（依法整理的操作清單）、`extractLaws.js`（官方原文連結）。
- **後端資料來源**：全國法規資料庫、勞保局、勞動部裁罰開放資料、職安署案例（由 AI-Ready-Data 組員整理上傳 EAP）。

## 七、限制與誠實標示

- 規則引擎清單與天數為「依法整理之操作參考」，UI 均標「僅供參考，以主管機關公告為準」，正式上線前建議再經法務複核。
- 風險定價只吃真實回傳的裁罰資料；無資料時不顯示數字。
- 後端 graph 路由具機率性，已由 proxy 並行搶答緩解；demo 以預錄影片呈現以確保穩定。
- 啟動：`npm run dev:all`（前端 + proxy 一起）；改 proxy/.env 後需重啟 proxy。
